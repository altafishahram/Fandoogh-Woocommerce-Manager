# Fandoogh Manager

پنل فارسی و راست‌به‌چپ مدیریت فروشگاه WordPress و WooCommerce، همراه وب‌اپ قابل نصب برای گوشی و دسکتاپ.

**نسخهٔ فعلی: ۱٫۴٫۳** — مالک پروژه تست این نسخه روی سایت اصلی را موفق اعلام کرده است. جزئیات تغییرات در [CHANGELOG](CHANGELOG.md) ثبت می‌شوند.

## نصب و شروع

1. ZIP نصب را از [آخرین انتشار](https://github.com/altafishahram/Fandoogh-Woocommerce-Manager/releases/latest) دریافت کنید.
2. در وردپرس، «افزونه‌ها ← افزودن ← بارگذاری افزونه» را باز کنید، ZIP را بارگذاری و افزونه را فعال کنید.
3. در منوی **Fandoogh Manager** کادر «راه‌اندازی و عملکرد افزونه» را بخوانید؛ دسترسی کاربر را تنظیم و در «اتصال گوشی» کد اتصال بسازید.
4. مسیر `/manager/` سایت را باز کنید و با نام کاربری، رمز وردپرس و کد یک‌بارمصرف وارد شوید.
5. در مرورگر سازگار، وب‌اپ را نصب کنید؛ روی آیفون از Add to Home Screen استفاده کنید.

پیش‌نیازها: WordPress 6.4 یا جدیدتر، PHP 7.4 یا جدیدتر، WooCommerce فعال و HTTPS برای اتصال امن، دوربین، میکروفن و اعلان گوشی. راهنمای همراه بسته در [package-readme.md](package-readme.md) است.

## قابلیت‌ها

- مدیریت محصولات ساده و متغیر، دسته‌ها، ویژگی‌ها، تصاویر، موجودی و قیمت‌گذاری گروهی.
- مدیریت سفارش، مشتری، کوپن، دیدگاه، یادداشت، رهگیری ارسال و بازپرداخت.
- فروش حضوری با انتخاب کالا از فهرست، جستجوی تایپی و صوتی، دوربین یا بارکدخوان؛ انتخاب تنوع و مشتری، معرفی مشتری جدید، اصلاح قیمت فقط برای همان فاکتور و تخفیف مبلغی/درصدی.
- ثبت دریافت نقدی، کارت‌خوان و ترکیبی، باقی‌ماندهٔ نقد و شمارهٔ پیگیری. رسید کارت‌خوان ثبت می‌شود؛ اتصال مستقیم به دستگاه کارت‌خوان وجود ندارد.
- پیش‌نمایش و چاپ فاکتور فروش حضوری و سفارش‌های قبلی در A4، A5 و فیش ۸۰ میلی‌متری، با مشخصات فعلی فروشگاه.
- گزارش مالی با فیلتر فروش حضوری، آنلاین و سایر سفارش‌ها؛ نمایش ناخالص، بازپرداخت و خالص فروش.
- کارهای امروز، هشدار عملیاتی گوشی با ساعت سکوت، اسکن بارکد و جستجوی صوتی فارسی در کادرهای جستجو.
- پنل راه‌اندازی، مدیریت دسترسی و نشست‌های دستگاهی، فونت وزیر محلی و آیکون وب‌اپ از آیکون خود سایت.

قیمت و موجودی فروش حضوری پیش از ثبت روی سرور تأیید می‌شوند و فروش موفق به سفارش WooCommerce تبدیل می‌شود؛ قیمت اصلی محصول تغییر نمی‌کند. نتیجهٔ نامعلوم فروش با همان شناسه پیگیری می‌شود و پس از خروج، برای همان فروشنده در همان تب باقی می‌ماند. تب را تا تعیین نتیجه نبندید.

مرجوعی از مبلغ، مالیات و تعداد باقی‌ماندهٔ هر قلم محاسبه می‌شود. بازپرداخت نامعلوم به بررسی سفارش و درگاه نیاز دارد و با گذشت زمان دوباره اجرا نمی‌شود. سفارش ناقص نیز فقط پس از تأیید حذف اجازهٔ تکرار همان درخواست را می‌دهد؛ سفارش دارای اثر پرداخت یا کاهش موجودی برای بررسی حفظ می‌شود.

صندوق به مجوزهای مشاهدهٔ کالا، مشاهده/ثبت سفارش و اجازهٔ تغییرات مهم نیاز دارد؛ معرفی و انتخاب مشتری نیز مجوز مربوط به مشتریان را می‌خواهد. افزایش مجوز یک نشست قدیمی با جفت‌سازی مجدد انجام می‌شود.

گزارش بر تاریخ ایجاد سفارش محاسبه می‌شود و شامل مالیات و ارسال است؛ خالص فروش به معنی سود یا وجه وصول‌شده نیست. سفارش‌های قدیمی فاقد نشان فروش حضوری در «آنلاین و سایر» قرار می‌گیرند. چاپ از دیالوگ مرورگر انجام می‌شود؛ اندازهٔ کاغذ متناظر را انتخاب و سربرگ/پابرگ مرورگر را خاموش کنید.

## ساختار مخزن

سورس فعال افزونه در ریشهٔ مخزن است؛ پوشهٔ قدیمی `fandoogh-manager/` حاوی نسخهٔ دوم سورس نگه‌داری نمی‌شود.

| مسیر | کاربرد |
| --- | --- |
| `fandoogh-manager.php` | ورودی افزونه، تنظیمات و مسیر وب‌اپ |
| `app/` | رابط وب‌اپ، ماژول‌های PHP و adapterهای WooCommerce |
| `assets/` | فایل‌های عمومی، فونت‌ها و دارایی‌های رابط |
| `languages/` | قالب ترجمه |
| `docs/` | معماری و راهنمای نگه‌داری؛ `archive/` اسناد تاریخی است |
| `tests/` | تست‌های PHP و JavaScript |
| `e2e/` | سناریوهای مرورگر Playwright |
| `tools/` | ابزار lint، پیش‌نمایش و ساخت/بررسی ZIP |
| `.github/workflows/` | بررسی خودکار کد و بستهٔ نصب |
| `dist/` | خروجی محلی ZIP؛ وارد Git نمی‌شود |

ZIPهای نصب در [Releases](https://github.com/altafishahram/Fandoogh-Woocommerce-Manager/releases) قرار می‌گیرند. فایل‌های build، وابستگی‌های Node، گزارش تست، پشتیبان و پیش‌نمایش محلی در Git ثبت نمی‌شوند. تاریخچهٔ نسخهٔ قدیمی `main` و شاخهٔ توسعه حفظ شده و به هم متصل است.

## توسعه و بررسی

برای ابزارهای توسعه، Node.js 20 یا جدیدتر و PHP لازم است:

```bash
npm ci
npx playwright install chromium webkit
npm run lint
npm run test:order-safety
npm run test:pos
npm run test:bulk-pricing
npm run test:analytics
npm run test:operations
npm run test:e2e:chromium
npm run test:e2e:webkit
```

Workflow گیت‌هاب تست‌های قرارداد محصولات، مشتریان، سفارش‌ها، امنیت، کوپن، دارایی‌ها، پنل و سرویس‌ورکر را هم اجرا می‌کند. تست‌های خودکار از بدل‌های WordPress/WooCommerce، API و سخت‌افزار استفاده می‌کنند. پذیرش روی سایت اصلی که مالک پروژه اعلام کرده، جدا از این تست‌هاست.

برای پیش‌نمایش بدون نوشتن روی فروشگاه:

```bash
node tools/static-server.js
```

سپس `http://127.0.0.1:8124/?preview=1` را باز کنید. این نما دادهٔ نمونه دارد.

برای ساخت بستهٔ قابل نصب:

```bash
npm run package
npm run package:check
```

خروجی `dist/fandoogh-manager.zip` فقط runtime و راهنمای نصب را شامل می‌شود. بررسی بسته، فهرست فایل‌ها و محتوای هر فایل را با سورس تطبیق می‌دهد.
