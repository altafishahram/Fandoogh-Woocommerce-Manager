# اسناد تاریخی

این پوشه اسناد و اسکریپت‌های پیشین `main` در commit [`9c7f99c`](https://github.com/altafishahram/Fandoogh-Woocommerce-Manager/tree/9c7f99ca024f7b4a2d77eb8aadd3961056696780) را حفظ می‌کند. مسیرهای پوشهٔ تودرتو، شمارهٔ نسخه‌ها و معیارهای پذیرش آن‌ها مربوط به همان ساختار قدیمی‌اند؛ اسکریپت‌های PowerShell اینجا در CI اجرا نمی‌شوند.

راهنمای فعال در [README اصلی](../../README.md)، [معماری](../ARCHITECTURE.md) و [تغییرات نسخه‌ها](../../CHANGELOG.md) است. برای نسخهٔ فعلی از `npm run lint`، تست‌های `package.json` و `npm run package:check` استفاده کنید.

- `runtime-staging-checklist.md`: چک‌لیست قدیمی تست سایت
- `vertical-slice.md`: قراردادها و طرح اولیهٔ API
- `woocommerce_admin_ui_ux_design.md` و `ui-ux-design-system-plan.md`: اسناد طراحی
- `ui-ux-redesign-prototype.html`: پیش‌نمایش طراحی قدیمی
- `acceptance-criteria.md`: معیارهای پذیرش قدیمی
- `verify-baseline.ps1` و `verify-release.ps1`: بررسی‌های قدیمی وابسته به مسیرها و نسخه‌های سابق

سورس و ZIP قدیمی در تاریخچهٔ Git باقی می‌مانند؛ نسخهٔ دوم runtime در شاخهٔ فعال نگه‌داری نمی‌شود.
